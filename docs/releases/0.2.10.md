# AegisCode 0.2.10

把长任务执行与经验复用放进同一套可审查的工作台。本版更新TypeScript、Vite、HTML/CSS前端与持久任务内核，Windows桌面入口仍是本机服务加浏览器页面。

## 新增能力

- 持久计划：按节点保存输入、依赖、结果和工具来源；缺少必需证据时阻断，契约失败最多重规划一次，共享动作预算不因重启重置。
- 计划工作台：查看当前步骤、工具证据、失败归档与重规划结果，刷新继续查看原任务。
- 技能按需召回：轻量元信息筛选、按版本加载正文，限制候选与注入数量，减少一次读取全部长正文的开销。
- 失败反馈修订：填写遗漏和约束，后台基于本次真实召回版本生成最多两项私有未验证草稿；重复反馈去重，原技能及权限保持。
- 修订审阅：技能库按需对照原方法和修订草稿，明确来源、版本及未验证状态；保存失败保留反馈说明，切任务或账号隔离。

保留原有真实模型增量预览、文件差异审批、多来源模型、项目多会话、通知、定时任务、资料引用、Skill导入导出和受控多Agent协作。

## 安装与使用

Windows用户下载`AegisCode-Setup.exe`，安装到空目录，再双击`AegisCode.exe`；免安装使用`AegisCode-portable.zip`，完整解压后运行。端口占用时换用`--port 8004`，或显式添加`--auto-port`。

Python用户在独立Python 3.12+环境安装wheel：

```powershell
python -m pip install ./aegiscode-0.2.10-py3-none-any.whl
aegiscode --port 8000
```

首次启动先注册账号，再按README在服务端配置模型来源；支持OpenAI兼容、自定义来源、Anthropic、Azure和Ollama。界面填写密钥环境变量名，实际凭证保存在服务端环境中。

升级前退出旧服务、备份数据，并将程序安装到新的空目录。冻结桌面程序默认数据为`%LOCALAPPDATA%/AegisCode`；程序与数据分离，不覆盖旧版本产物。旧库迁移先备份并使用现有显式迁移入口，具体步骤见README和安装指南。

技能草稿在启用前不参与召回；修订建议不自动替换原方法。请先核对来源，再用实际任务验证效果。计划结构通过并不保证业务结论正确，工具审批与用户权限仍由服务端执行。

下载后使用`Get-FileHash 文件名 -Algorithm SHA256`与`SHA256SUMS.txt`逐项核对。
