# 真实模型增量输出

本模块已包含于公开0.2.9安装器、便携版和wheel，安装器与wheel经独立安装专项；旧0.2.8下载包仍采用完整模型响应。工作台沿用TypeScript／Vite、HTML/CSS，不使用模拟打字动画。集成结果见[专项验收记录](升级方案/30-增量输出与持久结果恢复验收.md)，下载验证见[发布验收](升级方案/33-零点二九安装与公开发布验收.md)。

## 页面中的三个阶段

支持的模型来源将真正的公开文本片段返回服务端。输入区上方显示“模型输出中，尚未验收”；这是临时预览，不能视作任务已完成。服务端把文本节流写入持久事件，页面按游标读取，因此不是逐Token即时直推，也不承诺固定延迟。

模型转为调用工具时撤销本轮临时区域；完整组装和校验工具参数后，仍经过原有权限、风险与审批流程。工具参数碎片、reasoning／thinking字段及内部规划、反思、风险审查文本不展示。

收到任务终态立即停止临时展示，最终答复以保存的Run.answer为准。如果结果详情暂时不可读，页面提示重试，不继续声称任务正在输出。公开中间文本可能保留在本人历史事件中，不能把临时片段当作最终答案或全文证据。

## 模型来源与配置

OpenAI／Azure／兼容来源默认允许请求真实stream；管理员确认来源不支持时，在该路`AEGIS_MODELS_JSON`配置声明`"streaming": false`，保持完整响应。Anthropic首期使用完整响应，公开能力始终显示不提供该增量协议。配置不是连通验证，真实供应商仍需联测。

```json
{
  "model": "替换为已验证模型名称",
  "provider": "custom",
  "base_url": "https://your-model.example/v1",
  "api_key_env": "MY_MODEL_API_KEY",
  "streaming": false
}
```

流请求保留任务模型参数与完整兼容兜底。收到任何文本或工具语义片段后发生错误，会结束该轮并撤销临时输出，不换源拼接答案；首片段前的故障可按兼容候选回退。取消或超时关闭SDK流并释放并发槽，页面断开连接不会自行停止任务。

## 有界输出与断点读取

每轮公开文本最多131072字符，最多16个工具调用；每工具参数最多16384字符，总参数最多131072字符。首次片段立即保存，后续在字符／时间阈值下合并，单帧最多4096字符、最多256文本帧。帧达到上限只截断预览，完整结果仍在有界范围内组装；界面明确提示等待最终结果。

字符偏移按Unicode码点计数，中文和表情字符使用相同口径；临时内容以文本节点追加，HTML不执行。各轮独立call_id／seq，持久Event ID作为SSE恢复游标。重新打开或刷新只重读事件，不创建新任务；切页、退出与新任务清空临时区域。

请求发起前保存未完成标记，完整响应检查点后原子清除。进程崩溃或失租时，有未完成调用的任务进入interrupted，需要人工核对，不自动重新生成。完整结果已经保存、终态尚未落盘时，恢复直接复用持久答复，不再请求一次模型；尚未执行的反思仍须核对，已保存的反思不重复生成。已完成工具调用按账本复用，不再次执行。

## 验收与范围

验收包含真实SDK的HTTP SSE字节、延迟首片段、工具交错与截断、失败后禁止混合回退、取消、用量规范化、两Store读取及用户隔离。浏览器使用明确的确定性延迟模型，通过真实本机HTTP验证，不代表商业模型质量或生产延迟。

当前不新增编辑器、差异审阅、自动PR或共享集群容量门。部署与安装包状态以[需求矩阵](升级方案/23-全量需求核对与剩余交付.md)为准。
