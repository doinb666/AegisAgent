# AegisCode 0.2.7

本版本集中改善日常使用：重排工作台布局，完善长期记忆、技能、知识库和设置页面，源码、Windows 安装器、便携版与 wheel 提供同一套界面。

- 浅色增加暖灰、柔白、鼠尾草绿和浅青灰层次；保留石墨深色主题。
- 项目会话与任务历史切换显示，侧栏列表独立滚动；当前会话高亮，项目刷新保留展开状态。
- 收紧顶部工具栏，记忆与统计按需展开；项目标签与会话管理合并到输入区，模式附带中文说明。
- 内容管理支持已读取内容的名称、描述、标签、目录和状态筛选，每批展示 24 条；长正文按需展开，保存后定位内容。
- 名称和正文只含空白时阻止提交；版本冲突、扫描 PDF 422 等错误显示在表单附近，失败后保留输入；列表读取失败可重试。
- 模型配置提供操作步骤与复制入口；剪贴板不可用时选中文本供手动复制，过期复制响应不会覆盖已清空的配置状态。

安装：下载 AegisCode-Setup.exe 安装到空目录，或解压 AegisCode-portable.zip 后双击 AegisCode.exe。启动本地服务后从浏览器登录；不是原生 WebView 桌面壳。升级前备份数据与配置，不覆盖正在运行的旧安装目录。

模型需要自行配置。工具写入、代码执行和外部调用仍遵循权限与审批规则；执行沙箱需单独配置 Docker。安装包没有模型权重，未做代码签名。

当前未包含定时调度、附件、内嵌代码编辑器、差异审阅、自动 PR 和逐 Token 模型流。内容筛选作用于服务端已返回的本人资产，现有列表读取上限为 500 条，不声称跨全部历史分页搜索。

界面截图与功能验收使用独立测试数据和确定性模型，不代表商业模型质量、线上吞吐或历史简历效果指标。
