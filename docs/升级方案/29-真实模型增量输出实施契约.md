# 真实模型增量输出实施契约

承接第15号已确认P4。沿用现有模型路由、Run配置、Event表及持久SSE，不新增依赖和数据库表。本模块在0.2.8参数交付后实施；本计划不表示已经实现。

## 选择与边界

选择真实上游增量加持久分批展示。内存即时通道成本低，但跨进程重连无法共享；现有Event表节流写帧可以跨Store读取和恢复，代价是有限数据库写入及轮询延迟。界面显示“模型输出中，尚未验收”，不承诺毫秒级逐Token直推。

仅ReAct公开assistant.content展示临时帧，内部规划、反思、风险审查维持完整调用，不转发reasoning或thinking。公开中间文本可能保留于历史Event，不能称只存最终答复。出现工具增量时撤销本轮临时区域，完整校验后执行原工具流程；临时文本不写最终answer。

## 输入、输出与模块

模型路由输入有界messages、既有任务参数及内部增量回调；OpenAI／Azure／兼容协议消费真正stream，Anthropic首期完整响应降级。模型能力及协议差异仍由部署者联测，不根据名称猜测。消费全程持有已有并发槽，所有结束路径关闭SDK流。

按工具index组装调用ID、名称和参数，最多16项，参数及总文本有界。未收到合法结束、参数不完整或输出超限均不得执行工具。首个文本／工具语义增量前允许兼容来源回退，之后异常必须失败并撤销临时输出，禁止换源混合答案。

Worker为每轮建立call_id，发起请求前将未完成标记写入Run.config；网络等待不占数据库事务。帧以call_id、seq、偏移标识，在时间或字符阈值下节流写入Event。完整响应checkpoint与清除未完成标记原子完成；租约恢复遇未完成调用标记进入interrupted，不自动二次生成。

事件区分started、delta、retracted、finished；原Event ID继续承担SSE游标。前端使用独立临时区域和纯文本节点，按call_id／seq去重；出现撤销或终态停止临时展示，最终答案以Run.answer为准。重连只读事件，不重新创建任务或执行工具；退出、切页及新任务清理状态。

## 验收门

1. 真实首片段早于完整响应；完整响应来源不伪装增量。
2. 交错工具参数、文本后请求工具、缺结束、截断JSON及输出超限；任何不完整调用不执行。
3. 首语义增量前兼容回退，之后禁止回退与答案拼接；取消／超时关闭流并释放并发槽。
4. 发起前、首帧后、checkpoint前崩溃恢复为interrupted；保留工具账本未知副作用边界。
5. 两Store读取、断点恢复、重复帧、终态重连及用户隔离；不依赖进程内独占缓存。
6. reasoning、内部审查文本、工具参数碎片不公开；恶意HTML纯文本显示，长文本与事件数量有界。
7. 规格及质量审查后执行专项和适当回归，同步使用边界与截图，分批提交，不以旧延迟／费用指标代替实测。
