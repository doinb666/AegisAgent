# 模板、资料引用与MCP导览验收

日期：2026-10-07。实施第15号P3及第25号计划，基线`6fa1e31`。当前源码新增，无新增依赖或数据库表；旧0.2.7安装包不包含。

## 交付与边界

新增四内置模板、本人资料元信息分页、有界引用快照和MCP授权配置导览。模板不自动执行；资料不授予路径／工具权限，最多3份、各3000字符上限，并受任务实际上下文预算约束；目录只SQL投影ID／名称／版本。MCP仅配置目录，50服务×64工具上限，不向外部发请求，不显示URL和凭据。自定义模板、任意附件下载、外部连接诊断不是本批交付。

界面由task-inputs.ts组织模板、资料选择和MCP导览；HTML提供可见标签、替换确认与就近错误，CSS沿用浅绿模板说明、浅青灰验收要求。模板宽屏两列、窄屏单列；展开资料时收紧欢迎留白并收起推荐入口，保留说明与输入区空间。操作按钮44px、文本节点输出、浅深主题响应式；加载、缺能力、空目录、提交失败、截断资料均有文字状态。

## 测试与审查

后端先有2项行为失败后实施，相关专项及内核／定时回归69项通过（106.99秒）；8个后端／测试文件Ruff通过。真实SQLite／HTTP涵盖：跨用户与同企业其他成员、类型／状态／非空校验、最多3与去重、旧请求哈希、原键恢复快照、子任务不继承、MCP授权／不泄密／不发请求。SQL监听验证列表投影不读取正文或metadata。

真实浏览器通过：模板预填不创建Run、已有输入保留确认、真实上传资料并引用、公开来源版本、MCP空配置与503重试、浅深6组屏幕尺寸和退出清理。新增创建已提交但503响应丢失的原Run恢复、跨账号延迟预填、最多3项禁选与移除恢复、恶意名称无HTML节点、旧cap缺字段降级等负例均通过；展开资料后的欢迎说明可见范围断言通过，截图已重新生成。定时任务浏览器回归也通过。

规格审查发现模板await切页后写入旧账号输入：已改为同步切页后捕获上下文，等待后核对身份与页面代次，旧回调不得修改新视图。浏览器负例通过拦截旧Run响应后退出再释放验证，不以人工延时替代事件条件。

独立质量审查真实复现：合法4000字符上下文、三份长资料或默认预算配合16000字符任务时，原实现虽保存来源，但首次模型输入会静默裁掉整块资料。先补两个真实模型输入失败用例，再使用同一裁剪器二分分配预览；创建时无法容纳每份128字符／短全文则422回滚，不占幂等键。

项目准备的动态工具消息也计入首次任务／规划调用预算，再缩短时保存实际快照、截断元信息与内部标记；不足则明确失败，并提示已审批工具可能已完成。独立风险模型保持隔离，计划临时提示不写入持久消息；checkpoint保留动态元信息，防止局部旧config覆盖。后续轮次允许既有裁剪，不承诺永久保留资料。

规格复审进一步取得临界反例：4000字符预算、三份500字符资料及1200字符任务，审批工具结果1150字符时，plan预算不足原本被普通fallback吞掉，react仍能执行。先验证该负例失败，再引入专用DocumentContextBudgetError，仅对资料预算错误终止；普通计划错误仍保持回退。实现侧相关13项与原计划回退1项通过；独立规格原29项、临界动态6项通过。最终规格及质量复审均通过，无剩余阻塞项。修复前全量464通过、1跳过（352.63秒）及过程回归不混作最终源码的全量结果。

主控在最终冻结后重新运行P3两文件专项：31通过（45.95秒），11个变更后端／测试文件Ruff通过；前端TypeScript校验、Vite构建及浏览器脚本Ruff通过。中途启动的全量回归476通过、1跳过（426.87秒），其启动早于最后预算异常补丁，因此作为过程证据保留，最终全量在后续交付统一记录。

Windows验收服务曾出现WinError64；本机Python3.12.10 Proactor收到accept异常会关闭监听，已将就绪HTTP探测单次超时从1秒调整为5秒，服务启动总期限仍60秒。该调整只减少测试探测过早断连，不能声称已修复生产网络事件循环。缺入口的测试曾明确等待失败；CSP禁止字符串eval时改用Playwright属性断言，未放宽产品CSP。
