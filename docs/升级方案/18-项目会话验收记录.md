# 项目会话验收记录

日期：2026-10-07。范围：第17号计划T1–T3，当前源码；0.2.5公开下载包尚未包含。

## 交付行为

同一启用项目可创建多个独立会话，项目目标按需注入且不授予路径权限；新任务关联真实Thread与ThreadRun，顶层历史不混入子任务。支持私有项目树、会话改名、归档恢复、当前标签与稳定分页。创建会话使用用户行锁和唯一幂等键；相同请求返回原ID，参数变化409。

旧库默认隐藏新能力；显式迁移先预览，再备份，新增表与复合索引，保留原会话标识、请求哈希及任务内容。运行和会话组均分批200项处理。源码、wheel、EXE共用app内置迁移入口。

## 验收证据

- 新项目会话、HTTP和迁移测试：11项通过。覆盖同项目上下文分离、同企业成员／跨租户、viewer、非法参数、跨Store幂等、归档竞态、项目退役、重复迁移、备份拒绝、子任务排除和关联冲突回滚。
- 会话与历史合并回归：15项通过（29.23秒）。
- TypeScript检查与Vite构建通过，修改范围Ruff通过。
- 真实项目树浏览器：13项检查通过，无页面错误；独立临时SQLite、真实HTTP、确定性模型，包含归档后禁发、分页、注入与390/768px宽度。
- 完整工作台浏览器回归通过，无页面或非注入HTTP服务错误；一次详情500故障注入按预期恢复。
- 旧能力界面夹具：历史9项、编码18项通过，无页面错误和业务写请求。
- 全量首次回归：420通过、1跳过、1失败，耗时295.52秒。失败为历史投影测试捕获后台Worker查询的并发干扰；隔离背景Worker后该测试与相关15项回归通过。后续通知模块集成后统一复跑全量，不将首次结果表述为全量通过。

## 修复与清理

新任务读取成功后刷新会话；refreshTicket丢弃旧响应，分页按钮防重复并按ID去重；保留加载失败前已有项目会话。切换任务先清除旧项目标签；归档会话禁用发送，服务端仍执行409校验。导航可滚动且任务列表保留最小高度，避免内容增多后退出按钮或任务按钮无法点击。迁移CLI从scripts收敛到app，scripts只保留兼容入口。

## 当前边界

本轮不证明真实商业模型质量、性能收益、PostgreSQL恢复演练或大规模吞吐。PostgreSQL备份入口检查格式与非空，运维仍需独立恢复验证。项目迁移与隔离在SQLite实测，PostgreSQL专项迁移与查询计划尚未实测。正式数据预览顶层任务为0，未自动清理任何数据。
