# 定时任务闭环与验收

日期：2026-10-07。延续第15、17号已确认方案。当前源码新增，不包含于公开0.2.7包；安装包须从后续已提交快照重建并独立验收。

## 交付内容

- 私有Schedule／Occurrence、UTC一次性与固定间隔、唯一触发键、数据库租约、确定Run幂等键、版本CAS。
- 运行创建事务内复核身份与固定四工具白名单；执行开始与每次调用再次检查身份。不自动获得文件、MCP、代码、委派能力。
- 停机只补最近一次，旧未提交触发留痕跳过；旧已创建运行优先恢复，同计划未完成运行导致新触发跳过。
- 配额有限退避；未知异常不会终止后台循环，脱敏记录异常类型并保留租约恢复；取消不终止已创建任务。
- TypeScript管理页：计划创建、暂停、恢复、取消、触发记录、运行跳转、分页、就近错误与退出清空。
- 显式旧库备份迁移与启动器入口`--migrate-schedules`；默认预览、不删除旧任务资产。

设计：沿用暖灰导航、浅青灰说明区与浅绿状态；列表、表单、触发记录由独立schedules.ts组织，HTML提供标签与状态播报，CSS适配390／768／1440像素，44px操作区。正在更新、失败重试、无能力、空列表、已结束触发均有文字状态。

## 审查发现与修复证据

| 发现 | 修复及真实负例 |
|---|---|
| 批次开始时间掩盖真实租约到期 | 栅栏获得事务锁后读取即时clock，创建前复核，ACK加入expiry与令牌CAS；锁等待／召回期间过期回滚，旧ACK不终结新租约 |
| 崩溃恢复执行旧触发而非最新 | 旧未创建Occurrence被更新触发替代；已提交Run仍找回原运行，新触发受重叠门约束 |
| 默认步数变化破坏已创建Run恢复 | 调度恢复核对私有范围、schedule_id和确定键后直接返回原Run；普通手动请求保留哈希冲突检查 |
| 普通异常使后台调度永久退出 | 循环捕获普通异常、仅日志异常类型、有限退避；取消异常传播，关闭立即结束 |
| 响应丢失且时间已过不能重试 | 相同body保留原键恢复，首次新请求才要求未来时间；浏览器推进客户端时间2小时后仍只创建一个计划 |
| 旧详情与列表互相覆盖新状态 | 按id保留较大version；真实HTTP夹具返回旧版本时不回退，恢复请求仍成功 |
| 登录后过早切页列表不加载 | 能力配置完成后继续加载当前视图；浏览器保留能力响应直到切页后再释放 |

规格审查及质量审查独立进行，发现的问题均回修。code-simplifier清理了过期时间参数与分支、前端不存在的响应字段及重复原因映射；测试仍保留实际行为断言。
