## 安装发布

发布来源：`b100a68c5a934a3c4e2781ff9a5f2c026ef2982d`。`prepare_release` 从该 Git 快照构建安装器、便携 ZIP、wheel、源码 ZIP 和 SHA256 清单，未打包用户未提交的 Gradio、requirements 和独立文档改动。

```powershell
.venv/Scripts/python.exe -m scripts.prepare_release
.venv/Scripts/python.exe -m scripts.package_acceptance --setup dist/releases/0.2.7/AegisCode-Setup.exe --static app/web/app.js --port 8017
.venv/Scripts/python.exe -m scripts.package_acceptance --wheel dist/releases/0.2.7/aegiscode-0.2.7-py3-none-any.whl --static app/web/app.js --port 8018
```

Setup 与 wheel 均在独立中文临时目录验收通过；wheel 在全新 venv 安装并核对 app 来自安装环境。两者均验证新版静态 JS 的 SHA256、注册登录、能力接口、同项目两个独立会话、未配置模型时明确失败、私有失败通知和已读持久化、两项迁移 CLI 入口、重启后偏好自动加载。

便携 ZIP 与 Setup 使用同一 payload，Setup 解包后服务已验证；未额外声称独立便携视觉验收。EXE 为本地服务加浏览器工作台。
