## 最终设计

保留常见编码工作台的中央会话与底部输入，以绿色状态和记忆／技能／审查入口体现 AegisCode 的用途。

- 侧栏功能导航两列排列，「项目会话／任务历史」切换记录类型；列表独立滚动，账号和退出保留底部位置。
- 顶部工具栏收紧，主题按钮不再悬浮遮挡；「记忆与空间概览」按需展开。
- 浅色使用暖灰导航、柔白会话、浅鼠尾草绿选中项和用户消息、浅青灰审查；深色共享相同语义变量。
- 当前会话用背景与 `aria-current` 标记；项目树刷新保留展开状态。快捷搜索任务会自动打开历史并定位搜索框。
- 项目标签、重命名、归档与输入合并在同一区域；保留有界滚动，避免展开协作选项后遮挡控件。
- 技能入口使用「技能库」，保留 Skills 检索词；执行模式随选择显示解释；Fork、Team、Worktree 在审查信息中显示中文用途。
- 窄屏工具栏使用有名称的图标；键盘焦点、`aria-pressed`、`aria-current` 与原有错误反馈保留。

## 验收证据

命令：

```powershell
npm.cmd run frontend:verify
.venv/Scripts/python.exe -m ruff check scripts/layout_browser_acceptance.py scripts/run_ui_acceptance.py scripts/project_threads_browser_acceptance.py
.venv/Scripts/python.exe -m scripts.run_ui_acceptance --module scripts.project_threads_browser_acceptance --module scripts.notifications_browser_acceptance --module scripts.workbench_browser_acceptance --module scripts.layout_browser_acceptance
.venv/Scripts/python.exe -m scripts.coding_ui_acceptance --url http://127.0.0.1:8002 --output build/ui-layout-coding-final
.venv/Scripts/python.exe -m scripts.thread_browser_acceptance --url http://127.0.0.1:8002 --output build/ui-layout-thread
```

结果：TypeScript、Vite 构建和修改范围 Ruff 通过；项目会话 13 项、通知 10 项、完整工作台、代码界面 18 项、连续问答 9 项通过。最终会话标记函数清理后再次执行项目 13 项与布局验收，均通过。页面无未捕获脚本错误；完整工作台无非预期 HTTP 服务错误。

布局覆盖浅色／深色各 6 个视口：1440×900、1280×720、1024×768、768×1024、390×844、844×390，共 12 组。检查无页面横向溢出、发送按钮可滚动到完整可见且未被遮挡、协作选项可访问；极长会话标题与 HTML 注入文本没有生成图片节点。还验证概览展开、模式说明、建议只预填、快捷搜索定位、当前会话高亮和登录退出主题按钮位置。

工作台与通知包含 HTTP 500 故障注入，核对用户可重试；原有审批、文件预览、会话归档与分页功能保留。测试使用独立临时数据库和确定性模型，不代表真实模型泛化效果。本轮未重跑后端全量测试、Docker 沙箱或公开安装包验收。

本机 `http://127.0.0.1:8002/api/v1/health/ready` 返回 `status=ready`、`database=up`。通过系统命令打开浏览器被自动审批以 `blocked by policy` 拦截，页面需从链接访问。
