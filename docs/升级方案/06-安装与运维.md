# AegisCode 安装、配置与运维

## 交付入口

| 方式 | 输入 | 启动结果 | 数据位置 |
|---|---|---|---|
| 源码 | Python 3.12、运行依赖、模型环境 | `python -m app.launcher` | 当前目录 `data/` |
| wheel | `pip install dist/aegiscode-0.2.0-py3-none-any.whl` | `aegiscode` 命令 | 当前目录 `data/` |
| Windows 便携 | 解压整个 ZIP，保留 `_internal` | 双击 `AegisCode.exe` | `%LOCALAPPDATA%/AegisCode/` |
| Windows 安装器 | `AegisCode-Setup.exe`，空安装目录 | 安装目录中的 EXE | 同上，与安装目录分离 |
| 个人 Docker | Docker Desktop / Engine 与 Compose | 单 API + SQLite | Docker 数据卷 |
| 企业 Docker | Compose、数据库凭据 | 非 root API + PostgreSQL | API / PG 数据卷 |

浏览器默认访问 `http://127.0.0.1:8000`；首次创建个人账号会创建独立租户。企业管理员创建 operator/viewer 成员。所有资源默认用户私有，没有隐式企业共享。

源码 Windows 安装：`powershell -ExecutionPolicy Bypass -File scripts/install.ps1`。也可 `python -m venv .venv`、安装 `requirements-harness.txt`。完整旧组件与 Gradio 依赖保留在 `requirements.txt`；可选混合检索安装 `pip install .[rag]`。新版 wheel 的默认依赖支持 Harness，旧模块按需安装。

`python -m app.launcher --port 8001 --data-dir D:/AegisData --config D:/AegisConfig --no-browser` 可覆盖端口、数据、配置位置。EXE 使用同样参数，默认仅监听本机。退出终端或停止进程会关闭服务。远程企业访问需在自己的 TLS 入口后部署，默认 Compose 只发布本机端口。

## 模型与后台预算

复制 `.env.example` 为配置目录中的 `.env`，填写真实模型凭据。兼容单模型的 `OPENAI_API_KEY/OPENAI_API_BASE/OPENAI_MODEL`；多模型配置使用 `AEGIS_MODELS_JSON`，其中 `api_key_env` 指向密钥环境变量。服务启动读取 `.env`，不会把密钥回显到工作台。只支持 OpenAI 兼容工具调用，原生 Anthropic 协议尚无适配。

首选失败可切其他已配置 endpoint；同名模型在不同 endpoint 的连接和熔断独立。恢复探测窗口为60秒。任务10步预算包括规划、风险审查、反思和预留的子任务步数。`AEGIS_MAX_CONCURRENT_RUNS` 为每实例根任务槽，`AEGIS_MAX_CHILD_RUNS` 为专用子槽；两者分开避免父委派占满执行槽。多副本总容量为各实例容量之和，用户活动配额在数据库事务中约束。

`AEGIS_MAX_MODEL_CALLS` 限制每服务实例前台与后台的共享模型并发。后台经验提炼是另一个有界作业：每个 completed/failed 任务一轮，至多1600输出Token、4个候选、30秒超时；继承任务模型偏好，仍适用已配置的故障兜底。它额外产生模型费用，未计入前台10步。可用 `AEGIS_EVOLUTION_ENABLED=false` 关闭。提炼失败保留原始轨迹与基础候选，不无限重试；崩溃租约过期可重领，模型调用不承诺 exactly-once。

候选始终为 draft；用户需要单独启用提炼或修订过的版本。对原始工具轨迹的成功反馈只验证对应轨迹，不能自动验证提炼出的新步骤。技能修订保留服务器来源，撤销验证并回到草稿；退役后不召回。版本恢复保留完整历史。没有权重更新、在线 RL 或自动扩大工具权限。

## Docker

个人版：`docker compose -f docker-compose.personal.yml up --build -d`。

企业版：在环境设置自选 `POSTGRES_PASSWORD`，运行 `docker compose up --build -d`。PostgreSQL不发布宿主端口；API readiness 探测数据库，失败返回503。schema 初次自动创建，旧表不会自动迁移；后续生产升级应备份并执行有版本的迁移。

混合检索：合并 `docker-compose.rag.yml`，配置 embedding 模型、可选重排模型及 MinIO 凭据。该配置会安装重型模型依赖；默认 EXE 不包含这些模型。服务器仅在用户独立 Milvus 集合召回，并关联当前用户活动文档版本；外部服务失败明确降级BM25。实体镜像版本与真实模型检索质量需按部署环境实测；生产发布应将 MinIO 的 `latest` 换为实际验证的 digest。

## 沙箱与仓库

无执行器时拒绝代码执行，不使用宿主 subprocess 代替。执行器用非root执行容器、无网络、只读根、cap_drop、no-new-privileges、128MiB内存、0.5CPU、64PID、30秒和日志预算。仅把本人任务目录只读挂到 `/workspace`；写入在16MiB `/tmp`，持久输出走返回结果/artifact。模型写入任务文件仍须单独审批。

Linux 生产宿主合并 `docker-compose.sandbox.yml`：指定 `AEGIS_HOST_DATA_DIR` 的绝对路径、创建 `workspaces/` 并给API的UID10001写权限，设置独立 `AEGIS_SANDBOX_TOKEN`。执行器不发布端口，API不挂Docker socket。执行器本身可访问Docker API，须限定到内部可信运行边界；可替换rootless/gVisor/VM执行后端。

Docker Desktop 的Windows宿主路径不能直接假设等价于Linux执行器路径；本轮用Windows宿主SDK验证了同一执行器的真实隔离策略，Linux Compose执行器组合仍需各自部署验收。首次预拉 `python:3.12-slim`，离线环境请预置镜像，避免执行期间下载。

`AEGIS_REPOSITORY_ROOT` 仅由管理员显式绑定本地Git仓库。空配置不自动绑定当前目录。Fork导出HEAD快照，Worktree创建受控副本；禁止Git hooks、fsmonitor、归档符号链接与`.git`覆盖。Worktree不是执行沙箱，当前不自动commit/merge/push。

## MCP、恢复与备份

`AEGIS_MCP_SERVERS_JSON` 仅接受运维配置的HTTP/HTTPS服务，tools允许列表默认为空，token_env引用环境凭据。外部目录和调用都先审批；禁止URL内嵌凭据与重定向。接收预算2MB、独立超时；拒绝压缩响应避免解压绕过。MCP SDK可能把底层失败归纳为协议错误，原始网络错误不等于工具成功。

每个MCP配置必须显式绑定 `tenant_ids` 或 `user_ids`；都为空则不授权，两者同时配置时必须同时匹配。登录 `/auth/me` 返回真实身份标识，运维据此配置。工具schema的server枚举只包含本人获准服务，执行时再次授权；viewer禁止外部目录与调用。外部系统内部仍需自己的数据权限：同租户多人使用同一token意味着该服务的凭据范围共享；个人凭据请分别配置服务并绑定user_ids。

断网后SSE通过游标恢复，不重新提交执行。未知副作用状态为 interrupted，先人工核对后再创建明确的新任务；没有自动重复危险调用的“恢复”按钮。取消传播子任务；数据库暂时不可用时Worker退避，心跳失败停止当前执行，恢复后按持久日志处理。

个人备份需先关闭服务，再复制整个用户数据目录；在线备份需SQLite Backup API，不单独复制WAL模式主文件。企业数据库使用pg_dump或既有备份系统，文件/artifact目录一并保留。安装目录可以更换，卸载不删除独立用户数据；不自动清空任何历史卷。未执行签名或发布，干净Windows机器和企业网络环境需要独立验收。

个人认证限流目前每进程、每IP20次/分钟，入口限制请求字节；多副本生产入口需共享限流、TLS及请求超时。

文档解析使用固定的独立进程入口，最多两个同时解析、30秒等待及终止、512MiB进程内存和30秒CPU预算；Linux使用rlimit，Windows使用Job Object，无法设置资源预算时拒绝解析。输入不超过10MB、正文50万字符、标准输出8MB、错误输出64KiB，PDF逐页达到正文预算即停止；请求取消也终止进程。Docker与EXE预置分词编码缓存。该边界限制解析资源，不等于对第三方PDF解析器漏洞的完整文件系统/网络沙箱；公网服务可进一步使用专用无网络容器解析。

上传支持 `Idempotency-Key`；未指定时按同用户文件名与原始字节哈希去重。同键不同文档返回409；索引异常返回已保存的 document_id 和 pending 警告，同键重试复用原文档，向量故障保留BM25。此入口只对上传创建去重，不承诺外部向量写入exactly-once。
