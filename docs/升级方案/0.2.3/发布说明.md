# AegisCode 0.2.3：工作台与稳定性更新

源代码：438e97b23318db3345e2e83831365e572223cf9b。当前发布状态以 GitHub Release 实际页面为准。

## 安装与使用

- Windows：下载 AegisCode-Setup.exe，安装到空目录后双击 AegisCode.exe；也可解压便携 ZIP 并保留完整目录。
- Python 3.12+：安装本版 wheel 后运行 `aegiscode`；源码安装及 Docker 步骤见仓库 README。
- 默认仅监听本机。配置与数据默认位于 `%LOCALAPPDATA%/AegisCode/`，在该目录配置自己的 `.env` 模型参数并重启。
- 升级前备份配置和数据，退出旧服务，安装到新的空目录；默认独立数据目录保留，不删除用户数据。
- 文件校验和见 SHA256SUMS.txt。本版未做代码签名，安装包不包含模型权重。

## 本版变化

- 注册按钮执行表单校验；422 显示中文字段原因，保留后端密码规则。
- 防止畸形错误字段、原型属性和非 JSON 响应导致提示崩溃；不回显密码或服务原始输入。
- 浅色工作台采用浅灰侧栏、宽线程和底部圆角输入框；保留已有深色偏好。
- 新任务收起审查区，审批到来自动展开；空状态建议在新任务中仍可操作。
- 包含此前的 Windows 路径隔离、父子租约恢复、委派预算与完整回答引用修复。
- README 聚焦安装、配置、使用与亮点，技术栈已按实际主链路更新。
