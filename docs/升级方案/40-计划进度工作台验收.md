日期：2026-10-07。承接[第39号实施契约](39-计划执行进度工作台实施契约.md)，后端逐节点执行见[第38号](38-持久计划执行与恢复验收.md)。本批为源码增量，公开0.2.9安装包不包含新执行器和计划工作台。

## 本批行为

本人持久计划在审查区展示有序步骤、已通过数量、必需工具、验收原因和工具来源。重规划保留已完成前缀，旧未完成后缀可展开核对。刷新沿用同一任务和来源，不创建任务或重放工具。

结构通过不表示答案正确。拒绝审批、预算不足或未知结果时，未通过节点保持停止或待核对；Run完成事件不能直接把所有节点标成通过。无结构计划的旧任务和初始回退ReAct任务隐藏区域，回退原因保留在事件记录。

前端采用独立TypeScript模块、原生details/summary和语义色；当前及归档节点更新保留展开状态和焦点。最多8节点、2组归档及有界来源，不引入新API或执行权限。七类计划事件在计划区域和执行记录都采用公开字段投影，拒绝畸形、旧修订和未知节点事件的原始正文转储。

脚本使用随机本机端口和独立临时SQLite，不使用业务账号或业务库。选择了计划模块时设置`AEGIS_UI_PLAN=1`并使用20动作及20模型并发容量的夹具配置；组合中的其他模块共用该配置，故另做默认配置复验。生产默认仍为10动作。

Windows Proactor本机连接曾出现WinError64，使注册请求中断；仅Windows且计划模块开启时使用固定启动代码和端口argv选择Selector循环。默认验收和生产启动入口保持原样，此配置差异不能当作生产部署已验证。

## 边界与负例证据

| 场景 | 核对结果 |
|---|---|
| 两节点长任务 | 首节点通过后Run仍running；刷新保留同Run，最后2/2 |
| 工具来源恢复 | calculator来源与服务端验收报告一致，刷新来源文本不变，执行类事件未增加 |
| 重规划 | 保留n0-1完成前缀，新后缀n1-1；归档旧n0-2及缺证据原因 |
| 审批拒绝 | 1/2保持不变，未通过步骤停止，不宣称全部通过 |
| 预算耗尽 | 16项合法批次超出剩余共享预算，真实事件无tool_started，1/2停止 |
| 工具异常 | calculator的1/0实际进入interrupted；界面待核对，不伪装成普通失败 |
| 恶意目标 | HTML原样显示为文本，没有img节点或执行弹窗 |
| 畸形与过期事件 | 巨值、重复节点、非法修订、未知节点和伪造正确性标志不推进进度 |
| 公开字段 | 七类有效计划事件的顶层与嵌套额外内部字段不出现在整页text_content；非法事件无pre，说明不足200字符 |
| 焦点和主题 | 当前及归档summary更新后保持focus/open；深浅390、768、1440及减少动画通过 |
| 清空边界 | 切任务、新任务、离开任务空间、注销和换账号不残留旧计划 |

事件防御测试通过显式展示注入验证，不代表模型生成效果或真实外部工具执行。真实HTTP场景使用确定性模型；未据此报告商业模型成功率、Docker／PostgreSQL专项或生产吞吐。

## 审查中关闭的问题

主控视觉检查发现确定性夹具的最终汇总落入默认风险JSON；已精准匹配最终提示并增加中央答复无风险正文断言。归档曾在复用事件更新时整体重建，已改为按修订缓存details与节点，追加归档焦点负例。新增样式统一使用既有语义色。

规格审查独立复现：虽然计划组件过滤额外字段，执行记录仍将完整plan转储，内部reasoning、system_prompt、risk字段可见。修复后`publicPlanEvent`成为共同校验和投影入口，事件行接收是否实际采用的结果；畸形、过期和未知节点只显示短说明。独立复审核对冻结SHA并实测七类事件、嵌套字段及焦点，原缺口关闭。
