## 可以直接使用的精简项目描述

技术栈：Python、FastAPI、TypeScript、Vite、PostgreSQL/SQLite、Docker、MCP、原生工具调用；可选 Milvus、BM25、RRF 与 Cross-Encoder。

- **中心化多 Agent 协作：** 主 Agent 统一规划与审批，子任务按父权限子集只读执行；支持会话 Fork、独立 Team 和审批后的 Git Worktree，结合有界依赖图与工具账本验收保障协作可控。
- **Skill 能力与个人记忆：** 借鉴 Hermes 思想，将偏好、约束和成功/失败经验提炼为可审核记忆与 Skill 草稿；通过两阶段路由、来源追溯、指纹去重、反馈修订和退役，实现跨会话复用。
- **恢复与模型容错：** 实现幂等任务创建、Worker 租约、检查点和 SSE 断点重连；支持多来源模型路由与三态熔断，采用 60 秒恢复探测窗口。
- **权限与安全隔离：** 实现用户私有资源隔离、工具参数校验、路径边界和参数绑定审批；通过 Docker 沙箱限制代码执行权限、网络与资源。
- **检索与上下文优化：** 并行执行 BM25 与可选向量召回，结合 RRF、重排和降级；通过大结果外置与消息组裁剪控制上下文，避免截断工具调用配对。

## 不应直接沿用的历史表述

LangChain、LangGraph、Redis 已不属于当前默认主链路；Hermes 是设计参考，不是实际依赖。Redis 命中低于 50ms、Token 降低 40%、Top-5 提升 15% 缺少可复核的当前评测，不能作为本次验收结果。

可明确引用的工程参数为：默认 10 步、最多两个子任务、32 个 Skill 候选与最多 8 项注入、60 秒熔断探测窗口。参数不是效果指标。

本轮回归 393 通过、1 跳过；两路各注入 80ms 延迟的 5 轮合成检索基准中，串行中位数 176.55ms、并行 97.52ms，减少 44.76%。只能连同合成条件引用，不能扩展成生产性能承诺。
