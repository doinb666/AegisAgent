# AegisCode 0.2.4

正式工作台改为 TypeScript + Vite + HTML/CSS，安装后直接使用浏览器界面。运行已构建的 EXE 或 wheel 不需要 Node.js。

## 主要能力

- 多来源模型：OpenAI 兼容和自定义接口、Anthropic、Azure OpenAI、Ollama，支持优先级、权重与熔断降级。
- 中心化协作：Team、会话 Fork、经审批准备的 Git Fork/Worktree；子任务只读父工作区，两节点依赖图和独立工具账本验收。
- 个人偏好、约束和任务经验跨会话复用；Skill 草稿审核、反馈修订、导入导出和退役。
- 幂等任务、数据库租约、审批参数绑定、SSE 事件断点重连、Docker 执行沙箱。
- BM25 与可选向量召回并行，向量失败保留关键词检索结果。
- 修复 PostgreSQL JSON 行去重导致 Worker 无法领取任务的问题。

## 下载与使用

1. Windows 用户下载 `AegisCode-Setup.exe`，安装到空目录后双击 `AegisCode.exe`；或解压便携 ZIP，保留完整目录。
2. 默认在 http://127.0.0.1:8000 创建账号并登录。端口占用时可加 `--port 8001`。
3. 在 `%LOCALAPPDATA%/AegisCode/.env` 配置模型并重启。安装包不含模型权重，未配置模型时任务会明确失败。
4. 核对 `SHA256SUMS.txt`。升级选择新安装目录，保留独立数据目录并提前备份。

Python 用户安装 wheel 后执行 `aegiscode`；Docker 和源码部署见仓库 README。Windows 包尚未代码签名，不能替代企业环境的签名与部署审批。

## 验收边界

真实 Docker 沙箱和 PostgreSQL 双实例幂等、审批竞争、取消与恢复已验证。协议替身和确定性模型不证明商业模型任务质量；未复测历史 Token、缓存和召回率指标。子任务当前只读，不自动合并分支或生成 PR；模型回复未实现逐 Token 流。完整记录见仓库 `docs/升级方案/0.2.4/`。
