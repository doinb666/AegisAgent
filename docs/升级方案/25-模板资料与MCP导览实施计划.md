# 模板、资料引用与MCP导览实施计划

依据第15号已确认P3方案，继定时任务验收后实施。沿用Python／FastAPI／SQLAlchemy与TypeScript／Vite／HTML/CSS，不新增数据库表、依赖或任意宿主执行入口。

## 模块与契约

### 任务模板

输入：服务端维护的内置模板、当前可用工具。输出：模板ID、名称、说明、任务文本、所需工具及预期可验证输出。模板覆盖知识回答、只读代码审查、计算核对和任务复盘。

界面：独立探索入口，展示适用场景、输入与验收要求；选择仅预填输入区，保留用户已有正文并提示替换操作，不自动创建Run或提高工具权限。未具备所需工具时说明缺口，不伪造可执行状态。自定义模板CRUD及模板共享不是本批完成项。

验收：选择模板前后Run计数不增加；已有任务内容不静默丢弃；键盘可达、窄屏不溢出、账号退出不残留私有数据。

### 私有资料引用

输入：最多3个本人已解析且启用的document资产ID、任务、幂等键。输出：Run配置中有界的资料来源、版本、正文摘要预览、截断标记及hash；模型消息中的资料块标注为不可信数据，不授予路径或工具权限。

API：新元信息列表仅投影ID、名称、版本，最多50项、私有游标；`RunInput.document_ids`可选，未提供或空列表保留旧请求哈希。显式ID属于新请求身份，禁止重复ID、非文档、跨用户、跨企业、不存在、退役或空正文。重试返回原Run，不因文档后续修改或退役再次执行；快照可追溯。任务级预览不是全库检索替代，正文超预算截断需明确告知。

实现：在create_run原事务中读取有界资料、建立快照，避免第二次持久化窗口。资料块在最终用户任务之前注入；不解析或执行文档指令。子Agent及定时任务不自动继承资料选择；原只读权限门保留。

界面：输入区可刷新本人资料、选择及移除引用，上传仍复用知识库。运行创建失败保留选择及幂等键；新任务、账号切换清空；查看旧Run展示其保存的来源。解析失败不会创建Run。

验收：真实SQLite／HTTP验证本人引用、跨成员／企业、不同种类资产、空文档、退役、过量／重复ID、快照版本变化与原键重试；恶意文档不进入系统消息或改变工具白名单；浏览器上传、引用、失败保留与退出清理。

### MCP导览

输入：运维配置及本人授权。输出：获授权服务名称、配置的工具白名单、凭据配置是否就绪；不返回URL、密钥、环境变量值、其他用户授权或未授权服务存在性。工具及服务数量有界。

界面：展示“配置就绪／凭据缺失／未连接验证”，给出下一步；导览刷新不向外部服务发请求，不把配置就绪写为真实健康。实际工具发现和调用继续由Agent工具审批执行。只读角色无MCP服务可用，不接受网页提供的任意服务器自动安装。

验收：本人授权、同企业未授权成员、跨企业、viewer、无配置、缺凭据；断言响应无URL和token字段；证明目录接口不调用session/list_tools/call；真实外部连接专项另行记录。

## 顺序与交付门

1. 后端先写失败用例，完成有界目录、资料快照及可选请求字段，运行相关内核回归。
2. 前端独立模块接入capabilities：旧服务隐藏新增入口；过期响应丢弃，表单错误就近展示。
3. 真实本机浏览器验收，再按规格、质量两次审查与修复；code-simplifier只清理本批代码。
4. 更新README、使用指南、截图和能力矩阵；分模块提交推送。新包需独立构建安装，未发布前明确源码范围。

风险：资料可能含提示注入；保持不可信角色和审批边界，不能承诺彻底免疫。截断预览可能遗漏证据，应按需知识检索并标注不足。MCP导览不能充当外部服务可用性验证。任务模板不能自动覆盖已输入的用户约束。
