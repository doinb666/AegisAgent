# AegisCode 0.2.5

更新编码工作台的实际交互，延续 TypeScript + Vite、HTML/CSS 正式前端。

- 支持折叠导航、搜索快捷入口、键盘选择与焦点恢复。
- 模型回答支持安全标题、行内代码与代码块展示，复制失败时可手动复制；不执行回答中的 HTML。
- 优化任务列表、状态、SSE 和文件所有权查询，避免反复读取内部消息上下文。固定本机 SQLite 微基准中位读取延迟减少 40.30%，不代表 Token、缓存或生产吞吐指标。
- README 展示实际工作台与深浅主题，明确安装、使用方法和编码助手功能边界。

验证：394 项 Python 测试通过，1 项因 Windows 符号链接权限跳过；正式主链路静态检查和 TypeScript/Vite 构建通过。编码界面 18 项、模型及协作 8 项、注册负例 9 项及原有工作台/Skill 浏览器验收通过。

Windows 安装器安装到空目录后运行 AegisCode.exe；便携 ZIP 请保留完整目录。需要配置自己的模型服务，安装包不包含模型权重；Docker 沙箱需单独启用。当前构建未做代码签名。

已实现能力仍有边界：子任务只读；不支持内嵌编辑器、变更差异审阅、自动 PR/合并或模型逐 Token 流。技能与记忆自进化采用审核后的推理时复用，不在线修改模型权重。
