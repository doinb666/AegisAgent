# 文件差异审阅与安全保存验收

日期：2026-10-07。承接第31号契约与第15号已确认P4。独立规格和质量审查已通过，主控冻结全量回归593通过、2跳过；本模块源码验收通过。0.2.8安装包不包含本模块，安装与公开发布另行验收。

## 实现范围

模型仍仅提供`path/content`，服务端冻结工作区身份、文件及父目录身份、完整SHA、权限、调用与参数哈希。审批持久保存冻结契约，恢复复用，不重新读取最新文件作为旧审批基线。批准写入必须带精确`baseline_hash`；旧审批缺少基线时失败关闭，拒绝和其他工具兼容原接口。

审批前不创建目标目录。批准后在稳定的本机工作区锁内重验基线：文件变化、新增同名文件或目录替换时拒绝覆盖；已有文件使用同目录临时文件与原子替换，新建文件采用不覆盖发布。权限复制失败在发布前拒绝；发布结果未知或取消保留工具started账本，不自动重放。线程可能在协程取消后继续完成，不能承诺取消后零副作用。

工作台新增TypeScript差异组件，提供新建／修改、版本、差异、前后文本、截断提醒及完整参数展开。所有文件内容通过纯文本节点渲染。缺少有效冻结基线禁用批准，请求构造再次检查；终态、切页、新任务和退出清理差异。

## 发现及修复记录

1. 最初浏览器找不到差异区域，红测试失败；实现后真实HTTP批准、错误hash409、审批后同名文件保留等流程通过。
2. 发布体抛TimeoutError被外层误归为锁超时。将超时处理限定为获取锁阶段，发布后异常保留未知副作用，并以实际发布后超时复现验证。
3. Windows两类权限设置接口对AUTO_INHERITED标志处理不同。按原控制标志选接口并复制验证；protected／inherited专项在实际替换后读取目标权限比较。
4. 读取期间新增硬链接会绕过首次nlink检查。新增读取后复核opened／after／current，红绿负例验证拒绝冻结。
5. 旧审批请求延迟失败后，通用finally曾瞬时启用已因缺基线禁用的按钮；轮询稍后会再次禁用，单看最终状态会漏检。真实HTTP加延迟409与MutationObserver先复现失败，再改为按当前Run与共享校验恢复按钮，浏览器负例通过。
6. 独立规格审查指出缺少运行时发布后目标权限核对，以及发布前临时清理失败覆盖确定拒绝结果。已补齐目标核验；未发布的清理／解锁失败附说明并保留拒绝，发布后异常保持未知，新增8项负例通过。
7. 无末尾换行的旧／新文本差异可能拼接成同一行。已按差异记录补标准尾换行标记，保留原前后正文及完整SHA，覆盖无尾换行、仅尾换行变化等边界。
8. 后续浏览器回归两次在初始主题即时断言处失败，同时本机Windows测试服务出现WinError64接入异常。保留失败记录，在脚本增加页面错误、失败请求和事件绑定诊断；没有修改产品主题逻辑或把网络异常归为已修复。独立工作台和冻结后的五模块整组最终复验均通过。

## 验证边界

本地验证使用Windows、SQLite、真实HTTP及文件系统，模型为确定性验收替身。POSIX专项需在相应环境运行，商业模型、新增PostgreSQL和Docker专项未验证。

稳定锁仅协调本服务file_write通道，不包含project_prepare，不阻止任意不合作宿主程序，不是跨宿主原子CAS。锁文件拒绝链接、reparse与硬链接，释放后保留，不得在线清理。原文件只允许UTF-8普通文本，最多1MB；拟写参数最多12000字符。预览8192码点、diff16384码点，并对算法输入限制行数、行长，不能把预览当全文证据。

本批不提供通用编辑器、补丁合并、自动PR、可写子Agent或集群共享容量门。继续任务见[全量需求矩阵](23-全量需求核对与剩余交付.md)，用户操作见[文件审阅指南](../文件差异审阅指南.md)。
