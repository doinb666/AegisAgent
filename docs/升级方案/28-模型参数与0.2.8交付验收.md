# 模型参数与0.2.8交付验收

日期：2026-10-07。承接第27号契约，本记录区分源码验收、安装验收及公开发布。旧0.2.7包不包含本轮新增能力。

## 已实现

管理员按模型来源显式开放温度、输出字段与最大值、推理级别；默认不开放覆盖，不猜模型名。任务严格校验三类参数，空参数保持旧幂等哈希，非空参与请求身份；原任务恢复先于当前能力校验。故障回退仅使用完整兼容来源，不兼容候选不改变熔断状态。

主任务的规划、工具循环、反思及风险审查沿用参数。两类持久模型事件共用用量过滤，只保留四个标准字段及有界非负整数。后台经验提炼独立运行，不计为任务内核调用；子任务和定时任务不默认继承参数。

TypeScript参数模块与HTML原生表单、CSS响应式样式接入输入区。自动选择采用共同能力，切换来源清除不支持字段；保留值超过新上限时阻止提交，用户自行调整。失败保留输入，新任务／退出重置；旧服务隐藏入口。沿用柔白会话、暖灰导航与浅绿强调，参数按需展开，窄屏单列，避免挤压输入和说明。

## 审查中发现与修复

1. 任务调用计数测试混入后台提炼，出现真实偶发失败。仅在该计数测试关闭后台作业；保留独立演进测试及调用数断言。
2. 安装验收命令复用服务启动参数，迁移入口会收到不支持的参数。拆分服务命令与基础命令，迁移只接收数据目录。
3. 新用量事件过滤而旧事件仍可存入异常用量。抽取共同过滤函数；真实HTTP／SQLite负例验证布尔、负数、超大数和未知字段从所有模型事件排除，正常缓存用量保留。
