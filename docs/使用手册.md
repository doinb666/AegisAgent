# AegisCode 使用手册

## 登录与私有空间

启动后访问 `http://127.0.0.1:8000`。输入用户名及至少8位密码，点击「创建个人账号」，再登录。每个个人账号有独立租户；企业管理员通过「能力与设置」创建同租户的 operator 或 viewer。

admin能管理成员，operator能创建任务及修改自己的资产，viewer只能进行允许的只读操作。默认所有任务、文件、记忆、技能和文档都属于用户本人，同一企业其他成员也不能直接读取。API `GET /api/v1/auth/me` 可取得用户与租户标识，供管理员绑定MCP服务。

## 编码工作台操作

0.2.10可从[GitHub Release](https://github.com/doinb666/AegisAgent/releases/tag/v0.2.10)下载安装器、便携ZIP与wheel，包含持久计划、技能按需召回和反馈修订审阅。旧数据库先按[项目会话指南](项目会话使用指南.md)和[通知指南](站内通知使用指南.md)预览／备份迁移，再重启；全新数据库直接启用。下载包采用冻结源码，后续源码功能不自动进入已发布安装包。

同一项目可创建多个独立会话，分别讨论不同目标；标签显示当前项目与会话，支持重命名、归档与恢复。归档只整理列表，不停止后台任务；恢复后才能继续发送。顶部铃铛汇总本人完成、失败和审批提醒，点击标记已读并定位任务，不会自动批准工具调用。

「定时任务」支持一次性／固定间隔的后台只读任务及触发记录，暂停或取消计划不会停止已创建的任务。旧库必须显式备份迁移，源码与0.2.9安装包均提供；详见[定时任务使用指南](定时任务使用指南.md)。

「任务模板」提供知识回答、只读代码审查、计算核对和复盘。选择只预填任务，已有输入先确认替换；检查目标与验收要求后再发送。输入区展开「引用本人资料」，选择最多3份已上传的私有文档；任务保存来源版本与有界快照，截断时明确提示。创建失败保留输入与选择，原内容重试找回原任务。无需新增迁移，源码与0.2.9安装包均提供，详见[模板与资料引用指南](任务模板与资料引用指南.md)。

正式前端使用 TypeScript + Vite、HTML/CSS。顶部按钮分别折叠导航和审查区；窄屏首次加载收起导航。`Ctrl K`（macOS 为 `Cmd K`）打开可搜索的快捷入口，方向键选择、Enter 打开、Escape 关闭并恢复焦点；这些动作不会提交任务。`Alt N` 创建空任务，`Ctrl Enter` 发送当前输入。

侧栏使用「项目会话／任务历史」切换列表：前者管理独立会话及归档，后者提供任务搜索、状态筛选和分页；`Ctrl K` 搜索「搜索任务」会自动打开历史列表并定位搜索框。记忆加载与任务统计在「记忆与空间概览」展开查看。「技能库」即 Skills 管理入口。输入框下方解释所选执行模式，进阶协作选项仍在「代码工作区与协作」中。图解见[新版工作台指南](新版工作台指南.md)。0.2.9 安装包已包含该布局和内容管理优化。

回答支持标题、行内代码和代码围栏，代码块可以复制；剪贴板权限不可用时选中代码并提示手动复制。不解释回答中的 HTML，不自动打开模型给出的链接。任务文件列表仍为只读预览；当前源码另提供工具拟写文件的差异审批，尚无通用编辑器。

当前源码：打开任务会加载同一会话截至该任务的历史问答，每页最多 20 轮。点击「加载更早的问答」继续读取；失败时可单独重试，不影响当前任务答案。选中旧任务不会显示后续问答，子任务不会混入主会话。新任务和退出账号会使尚未完成的历史响应失效。历史展示不等于全部历史都进入模型上下文，模型仍遵守上下文预算。

Windows下载见[0.2.10 Release](https://github.com/doinb666/AegisAgent/releases/tag/v0.2.10)，三种模式独立安装通过，五项公开下载资产大小及SHA256一致。默认端口8000已占用时，在安装目录执行 `./AegisCode.exe --port 8002`，选择空闲端口；不会自动关闭占用端口的其他服务。

源码和 0.2.8 启动器可用 `--auto-port`，端口被占用时绑定空闲端口，实际地址显示在启动日志。默认仍保持指定端口，冲突时返回中文提示。自动打开页面以本进程初始化完成为条件；浏览器不可用会提示手动访问。Web 与 EXE 均支持技能管理；EXE 运行本地服务并打开浏览器，不是原生桌面壳。

## 准备记忆与资料

内容列表支持名称、描述、标签和目录搜索，以及候选／已启用／已退役筛选；首批展示24条，点击「显示更多」继续。正文先预览、按需展开；保存后定位内容。搜索作用于服务端当前已返回的最多500条本人资产，不是跨全部历史分页。修订冲突保留输入，先复制自己的修改，再刷新读取最新版本。操作和截图见[内容管理指南](内容管理指南.md)。

长期记忆中可保存「回答先给结论」「未经确认不能修改线上系统」等偏好与约束。添加后为草稿，检查内容再启用。约束进入上下文不等于新的权限，最终仍执行内核权限规则。

知识库支持TXT、Markdown和文本PDF，单文件最多10MB。扫描PDF需要先OCR。上传在独立有资源预算的解析进程完成；索引异常时资料仍保留，界面提示可重试。检索证据来自本人活动文档，向量后端不可用时降级BM25并说明。

项目记录目标与边界。点击「在此项目开始任务」后补充具体需求，后续任务可沿同一会话推进。仓库代码准备需管理员设置 `AEGIS_REPOSITORY_ROOT`，不会自动取得任意目录访问权。

## 执行、审批和反馈

桌面工作台左侧按任务内容搜索、按状态筛选，每页20项，可点击「加载更多任务」。顶部概览统计本人任务与资产；不会显示同企业其他成员的数据。右上角切换深色/浅色主题，选择保留在当前浏览器。

打开任务后，中央阅读任务线程，右侧查看审批、执行记录与文件。可折叠「任务审查」扩大线程；执行记录按需展开完整证据。点击文件名称只读预览文本，刷新列表不会触发工具执行。文件超过预览预算会明确截断，完整字节数仍保留。

「能力与设置」展示服务实际配置的模型、工具、沙箱与预算。配置存在不代表健康探测通过；无模型或沙箱时按页面指引由维护者设置本机环境并重启服务。页面不显示密钥，也不能通过任务提示词新增访问权限。

输入区可展开「模型参数」，按模型来源声明的能力调整温度、输出Token上限与推理强度。留空沿用配置，自动选择只开放共同能力；创建失败保留输入，新任务与退出重置。切换模型清除不支持字段，保留数值超过新上限时必须调整后提交。参数会随主任务的规划、执行和反思使用，不默认传给子任务或定时任务；源码与0.2.8安装包均提供。配置与API说明见[模型参数指南](模型参数使用指南.md)。

源码与0.2.9下载包支持真实模型文本增量预览：线程标明「模型输出中，尚未验收」，工具调用时撤销，任务结束立即切换到最终结果。刷新或断线只恢复原任务事件，不重复创建任务；结果详情短暂不可读时提示重新读取。来源不支持增量可配置`streaming: false`，Anthropic首期仍完整响应；旧0.2.8包未包含这一能力。限制与故障恢复见[增量输出指南](真实模型增量输出指南.md)。

当前源码的「我的外部工具」列出本人获授权的MCP服务、允许工具和凭据配置状态；刷新不连接外部服务，不返回URL和密钥。配置就绪不等于已验证连通，真实工具调用仍需通过权限与审批。

选择ReAct、Plan或Reflection，输入目标与验收标准。可用 `Ctrl+Enter` 发送，`Alt+N` 新建任务。未配置模型或模型不可用时显示失败，不制造回答。

源码与0.2.10下载包的Plan按持久节点逐步执行，节点依赖和必需工具经过结构验收才推进；已知契约失败最多重规划一次，未知副作用与拒批不会自动重试。默认10动作包含规划、节点模型、新工具、风险模型、验收和最终交付，最多8节点不等于默认能执行8节点，详见[计划执行指南](计划执行使用指南.md)。

右侧显示步骤、Trace ID和事件。预算超限停止，取消会向受控子任务传播；已保存的风险拒绝不能在恢复或人工批准后绕过。

工具需要审批时显示名称及完整参数。批准仅适用于此调用及这些参数，不能授权以后任意操作。viewer不具备写文件、执行代码、外部MCP等高风险能力。无隔离执行器时不会在宿主运行代码。

源码与0.2.9下载包的file_write审批展示新建／修改、差异、前后文本及冻结版本，批准后保存前再次核对。版本改变或出现同名文件时拒绝覆盖；检查「文件未写入」工具证据，不把模型最终描述当作保存成功。旧审批缺少基线时只能拒绝后重新提出修改。预览有截断上限，取消不能保证已开始的线程没有副作用。旧0.2.8安装包不含该能力，详见[文件审阅指南](文件差异审阅指南.md)。

任务结束后点击成功或失败。后台有界提炼候选画像、经验或Skill，保存在草稿中。检查来源、适用条件、失败原因及工具需求，再启用。修订过的来源资产撤销已有验证，重新审核。退役后不再召回，历史版本可查看并恢复。

失败反馈可附上遗漏、约束和期望，后台基于本次真实召回版本生成最多两项私有修订草稿；在技能库展开“对照原技能”核对原文和建议。原技能不会自动替换，修订草稿启用前不参与召回，生成建议不证明已修复。完整操作见[技能反馈修订指南](技能反馈修订指南.md)。

## 主控与只读子任务协作

可以在任务中要求「把两份文档分别交给只读子任务分析，再由主任务核对证据并汇总」。是否委派由支持工具调用的模型决定；工作台没有将请求自动转换为固定的协作流程。父任务始终持有控制权，子任务不能递归委派，每个父任务生命周期最多两个子任务。

`delegate` 的 `fork` 模式复制有界的父任务文本上下文，`team` 模式分别创建子会话。两种模式都只允许父任务已经获准的只读工具，不会自动扩大权限。仓库副本／Worktree 通过需要审批的 `project_prepare` 工具准备；准备成功后，子任务可在父子权限交集内读取父工作区的实时只读视图，仍不能写入、执行代码、调用 MCP、递归委派或自动合并。

模型可提交最多两个节点的小型依赖图。无前驱节点并行创建；后继节点仅在所有前驱通过独立验收后创建。验收检查数据库中的真实完成状态、非空答案、父子来源、工具账本和声明的 `required_tools`，不依赖答案中的成功声明。上游长答案保存为本人证据资产，后继只接收有界摘要与来源引用；前驱失败或证据不足时，后继标记为阻断。

创建整批子任务前检查共享步数、生命周期子数量及用户活动配额。ReAct至少保留一步主汇总；当前源码Plan另保留当前必要回答、后继节点最低成本与最终交付，已知不足不创建子任务。等待依据父任务剩余期限，并为主汇总预留时间；等待预算耗尽时先停止子任务，再返回数据库中的实际终态与原因。中途创建异常也会清理已创建的活跃子任务，不承诺跨工具的整批创建恰好一次。

子答案超过2000字符时，返回短预览、完整字符数和 `artifact_id`，完整回答保存在本人证据资产中并注明子任务来源。主任务有 `artifact_read` 权限时可以分页读取完整内容；引用不会额外授予权限，同企业其他用户也不能读取。

父任务终态后活跃子任务停止；租约恢复和执行边界也核对父状态。租约恢复或父生命周期失效清理时，已启动且结果未知的子工具保留 `interrupted`；显式取消保持取消状态并保留工具日志，不自动重跑。`completed` 表示执行循环结束；只有协作审查区显示“账本验收通过”才满足节点执行契约。该验收证明调用证据满足要求，不证明模型结论在语义上必然正确，主控仍需做最终质量判断。

## 断线与恢复

创建任务采用幂等键，同键同请求返回原任务，不创建第二份；同键不同内容返回409。页面断线后按SSE事件ID重新读取，重复事件去重。浏览器连接不是任务执行器，关闭页面不会自动取消任务。

状态 `waiting_approval` 等待用户处理；`failed` 表示已知失败；`interrupted` 表示工具副作用结果未知。后者不能自动重放危险调用，应先核对外部系统，再发起清楚的新任务。

## Skill 文件交换与渐进读取

在「Skills」点击「导入技能文件」，选择 UTF-8 的 SKILL.md 或本系统导出的 JSON 文件包。可设置逻辑目录，如 `coding/review`，不会读取宿主任意目录。导入默认候选，检查正文、工具声明及资源后再启用。

SKILL.md 示例：

```markdown
---
name: review-python
description: 对用户提供的Python代码进行只读边界审查
tags: [coding, review]
allowed-tools: [file_read]
---
先确认文件与验收目标，读取获准文件，检查空输入、异常和路径边界。
输出每个问题的证据与修复建议。修改文件或执行代码需另行审批。
```

文件仅支持 name、description、tags、allowed-tools 四类frontmatter。name为1–64位小写字母、数字与连字符，description非空、最长1024字符；tags最多32项每项64字符，allowed-tools最多32项每项128字符，也可用空格分隔字符串。工具名须使用AegisCode内核名称，如 `file_read`；外部生态中的Bash/Read等名称不会自动映射或获得权限。

「导出 SKILL.md」只含元信息与正文；「导出文件包」下载 `{document,directory,resources}` 的JSON，包含资源，可再次导入。重复新建导入会创建新资产，不承诺创建exactly-once。现有中文名称Skill导出时生成稳定英文slug，原名称用于描述。

点击资源按钮可审核草稿的文本资源，内容始终按纯文本显示。资源即使命名为 `scripts/example.py` 也不执行、不安装依赖。模型只会按需用 `skill_read` 读取本人已启用技能，召回预览只携带资源路径，不将全部资源挤入上下文。目录下拉框筛选精确目录。

SKILL.md最多32KiB、正文16000字符；最多16个资源，单项16000字节、总计64KiB。拒绝YAML别名/锚、重复键、非基础标签和过深节点；拒绝绝对路径、隐藏路径、反斜杠与点路径。ZIP与任意本地目录自动扫描暂不支持。

通用资产元数据的规范化UTF-8 JSON最多512KiB；Skill去除resources后的元数据最多8KiB。工具列表须为最多32项的文本列表，来源与新声明合并后也受此上限约束；不接受NaN、Infinity等非有限JSON数值。写入、导出与召回使用同一边界，异常旧记录不会挤掉有效候选。

修订表单保留资源、目录和工具声明，提交读取时的版本；如果其他操作已更新资产，则返回409，请重新打开当前版本再编辑。文件接口更新已有Skill也必须同时提供 `asset_id` 与 `expected_version`：

```http
POST /api/v1/skills/import
Authorization: Bearer <登录令牌>
Content-Type: application/json

{"document":"<完整SKILL.md文本>","directory":"coding/review","resources":{},"asset_id":"<资产ID>","expected_version":1}
```

新建时不提供最后两个字段。更新后仍为草稿，已有来源与工具依赖不会被输入文件伪造或清除。`GET /api/v1/skills/{id}/export` 导出文件包；`GET /api/v1/skills/{id}/resources?path=references/checklist.md` 审核本人资源，跨用户或跨租户访问返回404。

## API 示例

所有示例使用占位值，不包含真实凭据。

```http
POST /api/v1/auth/login
Content-Type: application/json

{"username":"你的账号","password":"你的密码"}
```

取响应 `token`，随后：

```http
POST /api/v1/runs
Authorization: Bearer <登录令牌>
Idempotency-Key: <此新任务的唯一键>
Content-Type: application/json

{"message":"根据我上传的文档总结结论并标注证据","mode":"react"}
```

查询 `GET /api/v1/runs/{id}`；订阅 `GET /api/v1/runs/{id}/events?after=0`，也支持 `Last-Event-ID`。审批调用 `POST /api/v1/runs/{id}/approval`，提交 `approved` 及当前审批对象的 `call_id`、`hash`（请求字段名为 `args_hash`）。不要复用旧审批参数。

当前源码批准file_write还必须提交`baseline_hash`，取自当前`approval.file_write.baseline_hash`；缺少时422，不匹配时409。拒绝及其他工具保持原契约，无新增数据库迁移。

### 任务检索与只读检查接口

`GET /api/v1/runs?query=关键词&status=completed&limit=20` 返回本人任务列表，默认最近100项。query最多200字符，百分号和下划线按字面搜索；status支持queued、running、waiting_approval、completed、failed、cancelled、interrupted。列表按创建时间和ID倒序；将本页最后一项的ID作为 `before` 查询下一页。本人子任务仍在列表中。合法的不存在或他人游标返回404，参数不合法返回422。

`GET /api/v1/workspace/overview` 返回本人任务状态、资产类型和状态的真实聚合统计，同租户管理员也不会隐式看到其他成员数据。

`GET /api/v1/runs/{id}/files` 返回 `{files:[{path,bytes}],truncated}`，最多200个文件、1000个扫描项和8层。`GET /api/v1/runs/{id}/file?path=result.txt` 返回 `{path,content,bytes,truncated}`；bytes为完整文件字节数，content最多64KiB且保留有效UTF-8字符，最大允许文件1MB。读取本人任务的合法路径前检查所有权，不创建工作区、不执行工具，也不需要写入审批；viewer可读取本人文件。

预览拒绝绝对/点路径、`.git`、Windows设备名、链接与junction、二进制和超限文件，不读取宿主任意目录。无法读取的文件返回404，不合法或不支持的预览返回422。链接检查针对静态路径；没有宣称可防御宿主进程在检查后并发替换文件或目录。

## 配置与费用

多模型 JSON 仅引用环境变量密钥，使用 `api_key_env`，不要把密钥写进 JSON 或 Git。工作台不提供读取服务器密钥的功能。源码及已发布 0.2.4 安装包支持 OpenAI 兼容（含自定义地址）、Anthropic 原生 Messages、Azure OpenAI 和 Ollama 兼容协议；设置页可生成配置示例，但不会直接保存或连接服务。协议适配有 SDK／HTTP 传输测试，真实服务连通和所选模型工具能力仍需部署者验证。配置字段及示例见 [多来源模型接入](多来源模型接入.md)。

后台提炼会增加模型调用费用；`AEGIS_EVOLUTION_ENABLED=false` 可关闭。它受独立超时和共享模型并发限制，不无限循环训练。

MCP由管理员设置服务URL、工具白名单及tenant_ids/user_ids。未绑定默认拒绝，同时配置两者取交集；不能在任务提示词中随意增加URL或工具。

备份需包含数据库与文件目录。个人离线备份先关闭服务再复制整个数据目录；在线SQLite不能只复制主库忽略WAL。企业使用数据库备份方案并保留文件资产。安装和部署细节见 [安装与运维](升级方案/06-安装与运维.md)。
