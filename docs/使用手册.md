# AegisCode 使用手册

## 登录与私有空间

启动后访问 `http://127.0.0.1:8000`。输入用户名及至少8位密码，点击「创建个人账号」，再登录。每个个人账号有独立租户；企业管理员通过「能力与设置」创建同租户的 operator 或 viewer。

admin能管理成员，operator能创建任务及修改自己的资产，viewer只能进行允许的只读操作。默认所有任务、文件、记忆、技能和文档都属于用户本人，同一企业其他成员也不能直接读取。API `GET /api/v1/auth/me` 可取得用户与租户标识，供管理员绑定MCP服务。

## 准备记忆与资料

长期记忆中可保存「回答先给结论」「未经确认不能修改线上系统」等偏好与约束。添加后为草稿，检查内容再启用。约束进入上下文不等于新的权限，最终仍执行内核权限规则。

知识库支持TXT、Markdown和文本PDF，单文件最多10MB。扫描PDF需要先OCR。上传在独立有资源预算的解析进程完成；索引异常时资料仍保留，界面提示可重试。检索证据来自本人活动文档，向量后端不可用时降级BM25并说明。

项目记录目标与边界。点击「在此项目开始任务」后补充具体需求，后续任务可沿同一会话推进。仓库代码准备需管理员设置 `AEGIS_REPOSITORY_ROOT`，不会自动取得任意目录访问权。

## 执行、审批和反馈

选择ReAct、Plan或Reflection，输入目标与验收标准。可用 `Ctrl+Enter` 发送，`Alt+N` 新建任务。未配置模型或模型不可用时显示失败，不制造回答。

右侧显示步骤、Trace ID和事件。默认10步包括规划、风险审查、反思和预留子任务预算，超限停止。取消会向受控子任务传播。

工具需要审批时显示名称及完整参数。批准仅适用于此调用及这些参数，不能授权以后任意操作。viewer不具备写文件、执行代码、外部MCP等高风险能力。无隔离执行器时不会在宿主运行代码。

任务结束后点击成功或失败。后台有界提炼候选画像、经验或Skill，保存在草稿中。检查来源、适用条件、失败原因及工具需求，再启用。修订过的来源资产撤销已有验证，重新审核。退役后不再召回，历史版本可查看并恢复。

## 断线与恢复

创建任务采用幂等键，同键同请求返回原任务，不创建第二份；同键不同内容返回409。页面断线后按SSE事件ID重新读取，重复事件去重。浏览器连接不是任务执行器，关闭页面不会自动取消任务。

状态 `waiting_approval` 等待用户处理；`failed` 表示已知失败；`interrupted` 表示工具副作用结果未知。后者不能自动重放危险调用，应先核对外部系统，再发起清楚的新任务。

## Skill 文件交换与渐进读取

在「Skills」点击「导入技能文件」，选择 UTF-8 的 SKILL.md 或本系统导出的 JSON 文件包。可设置逻辑目录，如 `coding/review`，不会读取宿主任意目录。导入默认候选，检查正文、工具声明及资源后再启用。

SKILL.md 示例：

```markdown
---
name: review-python
description: 对用户提供的Python代码进行只读边界审查
tags: [coding, review]
allowed-tools: [file_read]
---
先确认文件与验收目标，读取获准文件，检查空输入、异常和路径边界。
输出每个问题的证据与修复建议。修改文件或执行代码需另行审批。
```

文件仅支持 name、description、tags、allowed-tools 四类frontmatter。name为1–64位小写字母、数字与连字符，description非空、最长1024字符；tags最多32项每项64字符，allowed-tools最多32项每项128字符，也可用空格分隔字符串。工具名须使用AegisCode内核名称，如 `file_read`；外部生态中的Bash/Read等名称不会自动映射或获得权限。

「导出 SKILL.md」只含元信息与正文；「导出文件包」下载 `{document,directory,resources}` 的JSON，包含资源，可再次导入。重复新建导入会创建新资产，不承诺创建exactly-once。现有中文名称Skill导出时生成稳定英文slug，原名称用于描述。

点击资源按钮可审核草稿的文本资源，内容始终按纯文本显示。资源即使命名为 `scripts/example.py` 也不执行、不安装依赖。模型只会按需用 `skill_read` 读取本人已启用技能，召回预览只携带资源路径，不将全部资源挤入上下文。目录下拉框筛选精确目录。

SKILL.md最多32KiB、正文16000字符；最多16个资源，单项16000字节、总计64KiB。拒绝YAML别名/锚、重复键、非基础标签和过深节点；拒绝绝对路径、隐藏路径、反斜杠与点路径。ZIP与任意本地目录自动扫描暂不支持。

通用资产元数据的规范化UTF-8 JSON最多512KiB；Skill去除resources后的元数据最多8KiB。工具列表须为最多32项的文本列表，来源与新声明合并后也受此上限约束；不接受NaN、Infinity等非有限JSON数值。写入、导出与召回使用同一边界，异常旧记录不会挤掉有效候选。

修订表单保留资源、目录和工具声明，提交读取时的版本；如果其他操作已更新资产，则返回409，请重新打开当前版本再编辑。文件接口更新已有Skill也必须同时提供 `asset_id` 与 `expected_version`：

```http
POST /api/v1/skills/import
Authorization: Bearer <登录令牌>
Content-Type: application/json

{"document":"<完整SKILL.md文本>","directory":"coding/review","resources":{},"asset_id":"<资产ID>","expected_version":1}
```

新建时不提供最后两个字段。更新后仍为草稿，已有来源与工具依赖不会被输入文件伪造或清除。`GET /api/v1/skills/{id}/export` 导出文件包；`GET /api/v1/skills/{id}/resources?path=references/checklist.md` 审核本人资源，跨用户或跨租户访问返回404。

## API 示例

所有示例使用占位值，不包含真实凭据。

```http
POST /api/v1/auth/login
Content-Type: application/json

{"username":"你的账号","password":"你的密码"}
```

取响应 `token`，随后：

```http
POST /api/v1/runs
Authorization: Bearer <登录令牌>
Idempotency-Key: <此新任务的唯一键>
Content-Type: application/json

{"message":"根据我上传的文档总结结论并标注证据","mode":"react"}
```

查询 `GET /api/v1/runs/{id}`；订阅 `GET /api/v1/runs/{id}/events?after=0`，也支持 `Last-Event-ID`。审批调用 `POST /api/v1/runs/{id}/approval`，提交 `approved` 及当前审批对象的 `call_id`、`hash`（请求字段名为 `args_hash`）。不要复用旧审批参数。

## 配置与费用

多模型JSON仅引用环境变量密钥，使用 `api_key_env`，不要把密钥写进JSON或Git。工作台不提供读取服务器密钥的功能。当前模型协议为OpenAI兼容工具调用，原生Anthropic协议尚未适配。

后台提炼会增加模型调用费用；`AEGIS_EVOLUTION_ENABLED=false` 可关闭。它受独立超时和共享模型并发限制，不无限循环训练。

MCP由管理员设置服务URL、工具白名单及tenant_ids/user_ids。未绑定默认拒绝，同时配置两者取交集；不能在任务提示词中随意增加URL或工具。

备份需包含数据库与文件目录。个人离线备份先关闭服务再复制整个数据目录；在线SQLite不能只复制主库忽略WAL。企业使用数据库备份方案并保留文件资产。安装和部署细节见 [安装与运维](升级方案/06-安装与运维.md)。
