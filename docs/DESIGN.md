# 工作台视觉方案

开发者在明亮办公环境的桌面显示器上持续阅读代码任务与审批证据；依据用户提供的 1.png，采用浅灰侧栏与浅色宽线程，默认浅色，保留深色石墨主题。已有本机主题偏好优先。中文使用本地无衬线字体，正文最长 72ch。

桌面由任务侧栏、中央线程和可折叠审查区组成；新任务默认收起审查区，打开已有运行时呈现证据。输入区位于线程底部，使用单一轻阴影和 24px 圆角，无渐变和装饰指标。侧栏提供任务搜索、状态筛选和有界分页；右侧逐项呈现审批、执行证据和只读文件预览。窄屏将导航和审查转为独立可访问区域，避免横向溢出。

色彩以 CSS 变量和 OKLCH 定义；按钮、输入、列表共享圆角和 focus 样式。状态包括 idle、loading、running、waiting_approval、completed、failed、cancelled、interrupted 与 reconnecting。审批展开在任务区，内容以纯文本展示。动画仅用于 150–200ms 状态过渡，减少动画设置禁用。

首版使用同源静态 HTML/CSS/JS，避免 EXE 安装依赖 Node。用户输出与工具参数通过 textContent 渲染，禁止不可信 HTML。持久事件以 ID 去重；网络失败重试读取事件，不重发任务创建。

正式源码使用 TypeScript + Vite，继续输出同源静态页面。导航可折叠，窄屏首次加载默认收起；快捷跳转采用可搜索的内联区域，保留自然 Tab 顺序与 Escape 焦点恢复，不创建遮罩。模型代码块以纯文本渲染，复制成功与剪贴板失败均展示明确反馈；不把文件预览伪装成编辑器。深浅主题共享语义色与组件尺寸。

当前源码优化：桌面侧栏 260px，宽屏 280px；功能导航分为两列，「项目会话／任务历史」切换列表，列表独立滚动，账号与退出固定在底部。顶部工具栏约 82px，主题按钮进入工具栏；记忆与统计按需展开。项目树保留刷新前的展开状态，以背景色和 aria-current 标记当前会话。

浅色增加相近色层次：暖灰导航、柔白会话、鼠尾草绿选中与用户消息、浅青灰审查。由 --rail、--paper、--accent-light、--soft、--soft-alt、--panel 统一映射；深色保留相同语义。项目标签、会话管理与输入框组成同一底部区域；协作设置展开后可在区域内滚动。窄屏工具栏改用带可访问名称的图标，保留记忆概览和可见键盘焦点。所有现有安全审查仍由服务端决定。
