# AegisCode 工作台与编码助手能力

AegisCode 借鉴编码助手的任务侧栏、中央线程、底部输入区和证据审查区，使用自己的名称、配色与记忆/Skill 审核流程。正式前端为 TypeScript + Vite、HTML/CSS，同源部署于 FastAPI，可随 Windows 安装包离线提供静态资源。这里描述实际实现，不代表复用了 Codex 私有代码。

## 功能入口与范围

| 常见编码助手交互 | AegisCode 入口 | 实际能力与边界 |
|---|---|---|
| 新任务与历史记录 | 左侧新任务、任务搜索、状态筛选、加载更多 | 已接通持久任务；本人资源隔离 |
| 连续会话 | 打开任务后的历史问答、加载更早的问答 | 当前源码分页展示截至选中任务的问答；子运行独立，过期响应不回填 |
| 项目下多个会话 | 项目与会话、当前项目标签 | 当前源码支持私有线程、改名、归档恢复和分页；旧数据库先备份迁移 |
| 任务提醒 | 顶部铃铛、站内通知 | 事件同事务生成，未读与已读持久保存，点击定位；不自动审批 |
| 定时执行 | 侧栏「定时任务」 | 当前源码支持一次性／固定间隔只读计划、租约恢复与触发记录；旧库显式迁移 |
| 探索模板 | 侧栏「任务模板」 | 四种内置模板展示能力和验收要求，仅预填，不自动执行 |
| 任务资料 | 输入区「引用本人资料」 | 最多3份私有启用文档，预算内快照与来源版本；不是任意附件下载或全文保证 |
| 外部工具导览 | 设置中的「我的外部工具」 | 本人MCP授权配置与工具白名单，不展示凭据或将配置当连通 |
| 聚焦线程 | 顶部导航/审查折叠按钮 | 两侧均可折叠，窄屏默认收起导航 |
| 键盘操作 | Ctrl K / Cmd K、Alt N、Ctrl Enter | 搜索入口、开新任务、发送；快捷跳转不会提交任务 |
| 模型选择 | 输入区模型选项、能力与设置 | 选择配置来源；配置生成器仅生成环境变量示例 |
| 任务模型参数 | 输入区「模型参数」 | 显式能力开放温度、输出上限和推理强度，兼容来源兜底；非费用硬配额 |
| 规划与工具执行 | 执行方式、任务审查 | ReAct、先规划、反思；持久任务状态和执行证据 |
| 模型增量预览 | 线程内独立临时文本区 | 源码与0.2.9包消费真实文本delta，分批持久化；工具调用撤销、终态核对；旧0.2.8包仍完整响应 |
| 代码阅读 | 回答代码块、任务文件预览 | 安全代码围栏与复制；文件列表只读，尚无通用编辑器和语法高亮 |
| 文件差异审阅 | file_write审批中的差异及前后对照 | 源码与0.2.9包绑定冻结基线，变化拒绝覆盖、旧审批失败关闭；有界预览，旧0.2.8包不含 |
| 危险操作审批 | 右侧精确工具及参数审批 | 已接通真实批准/拒绝；未知副作用不自动重放 |
| 多 Agent | 代码工作区与协作、协作与独立验收 | 最多两个只读子运行；支持会话 Fork、Team 和审批后的 Worktree/代码副本准备 |
| 开发者 Git 工作流 | 管理员绑定仓库、准备工作区 | 不支持子任务写仓库、自动合并或一键创建 PR |
| 长期个性化 | 长期记忆 | 用户偏好、约束、情景和程序性经验，登录加载与任务召回 |
| 可成长的技能 | Skills | 候选审核、版本修订、反馈和退役；权限规则不会自行演化 |
| 企业访问 | 登录、成员管理、工具边界、Docker 沙箱 | 角色和用户隔离；大规模集群共享限流仍需补齐 |

## 视觉与特色

采用浅灰侧栏、宽线程和圆角输入区，保留石墨深色主题。品牌以绿色小标记与必要的操作状态呈现，避免让装饰挤占代码阅读区域。AegisCode 的特色是把记忆与技能审阅、精确工具审批、独立子任务验收放在同一工作台。
