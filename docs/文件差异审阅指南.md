# 文件差异审阅

本模块源码已通过独立审查、全量测试和浏览器验收，属于0.2.8发布后的源码功能，尚未包含在0.2.8安装器、便携版或wheel中。正式工作台沿用TypeScript／Vite、HTML/CSS。

## 查看与批准修改

描述目标，例如：“在本任务工作区创建说明文件，写清输入、输出和验收方式，保存前让我查看修改。”模型提出file_write时，右侧「需要你的批准」展示文件名、新建或修改类型、差异和版本提醒。

差异中`+`表示新增，`-`表示删除，不只依赖颜色。展开「对照前后内容」查看文本，展开「查看完整工具参数」核对完整拟写内容。较大的原文件和差异只展示局部，页面会提示截断；证据不足或修改范围不明确时可以拒绝。

批准只授权当前文件版本及本次拟写内容。服务端保存前再次核对版本：原文件被修改、目录被替换或审批后出现同名新文件时，拒绝覆盖并保留现有文件。任务审查显示「文件未写入」及原因。模型最终说“完成”不能替代工具结果；检查文件列表和工具证据，必要时要求新的修改调用。

刷新和重新打开任务复用已冻结的版本，不重新绑定最新文件。旧审批缺少有效基线时页面禁用批准，可拒绝后重新提出任务。停止任务不保证正在运行的文件线程毫无副作用，出现「需要人工核对」时先核对实际文件和账本。

## 范围与限制

仅允许本人当前任务工作区，不开放任意宿主路径写入。viewer、子任务和定时任务不能写文件。原文件只接受UTF-8普通文本，最多1MB；拟写参数最多12000字符。链接文件、硬链接、目录越界及二进制原文件拒绝。前后预览各最多8192码点，差异最多16384码点，算法还限制行数和行长；预览不能作为全文证明。

本机Aegis的file_write通道使用稳定工作区锁，等待最多5秒；锁超时返回未写入结果。项目准备不包含在这一锁协议中。合作锁不能阻止任意外部程序修改文件，不是跨宿主原子CAS；共享文件系统部署需另行验证。部署目录应由受信服务身份管理。

已有文件通过临时文件和原子替换发布，新文件采用不覆盖发布。Windows复制原DACL及保护／继承标志，POSIX保留mode并拒绝不同归属；权限复制失败会在发布前拒绝。扩展属性和任意文件元数据不属于本批复制范围。私有`workspace-locks`目录的锁文件不会在解锁后删除，请勿在线清理它们。

当前仍不提供通用编辑器、任意补丁应用、自动合并或一键PR。Worktree准备仍是独立、受审批的代码工作区，不自动将修改合并回绑定仓库。

## API客户端升级

读取本人`GET /api/v1/runs/{run_id}`返回的`approval`，批准file_write时向既有`POST /api/v1/runs/{run_id}/approval`提交原`call_id`、`args_hash`及新增`baseline_hash`。基线取自`approval.file_write.baseline_hash`，不能自行生成、由模型提供或从其他任务复制。

缺少基线返回422，过期或不匹配返回409。拒绝及其他工具仍沿用原call_id与args_hash；不需要新增数据库迁移。执行结果`status: rejected`与`code: baseline_conflict`表示目标未被覆盖，不应把HTTP审批成功误当文件保存成功。
