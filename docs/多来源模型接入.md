# 多来源模型接入

本文新增原生协议适用于更新源码；已发布 0.2.3 安装包仍仅含原有 OpenAI 兼容入口，安装包更新以后续版本说明为准。

在服务读取的 `.env` 中配置 `AEGIS_MODELS_JSON`，修改后重启。源码支持五种配置值：`openai`、`custom`（均为 Chat Completions 兼容协议）、`anthropic`（原生 Messages）、`azure`、`ollama`。这表示协议支持，并不保证每家服务及每个模型都支持工具调用。

## 自定义兼容服务与备用模型

```dotenv
PRIMARY_MODEL_KEY=填写自己的主服务密钥
BACKUP_MODEL_KEY=填写自己的备用服务密钥
AEGIS_MODELS_JSON='[{"provider":"custom","label":"主服务","model":"填写模型名","base_url":"https://your-service.example/v1","api_key_env":"PRIMARY_MODEL_KEY","priority":0},{"provider":"openai","label":"备用服务","model":"填写备用模型名","api_key_env":"BACKUP_MODEL_KEY","priority":1}]'
```

兼容协议可接入支持该接口的 DeepSeek、通义千问、Gemini 兼容入口或自建服务；请从提供方文档填写地址及模型名，未对这些商业端点逐一联测。`base_url` 是基础地址，不是 `/chat/completions` 完整路径。

## Anthropic 原生与 Azure

```dotenv
ANTHROPIC_MODEL_KEY=填写自己的密钥
AZURE_MODEL_KEY=填写自己的资源密钥
AEGIS_MODELS_JSON='[{"provider":"anthropic","label":"Claude 原生","model":"填写可用模型ID","base_url":"https://api.anthropic.com/v1","api_key_env":"ANTHROPIC_MODEL_KEY","priority":0},{"provider":"azure","label":"Azure 备用","model":"填写部署名称","base_url":"https://your-resource.openai.azure.com","api_version":"2024-10-21","api_key_env":"AZURE_MODEL_KEY","priority":1}]'
```

Azure 的 `model` 为部署名，`base_url` 为资源根地址，必须显式设置该资源支持的 `api_version`。Anthropic 适配文本、工具调用及工具结果，归一化为同一个任务执行内核；不包含图像输入、扩展思考签名或订阅登录接入。

## 本地模型

本机先安装并启动 Ollama，下载支持工具调用的模型，再配置：

```dotenv
AEGIS_MODELS_JSON='[{"provider":"ollama","label":"本机模型","model":"填写已下载模型名"}]'
```

默认地址为 `http://127.0.0.1:11434/v1`，不需要密钥环境变量。也可显式填写本地代理地址及 `api_key_env`。Docker 内的 `127.0.0.1` 指容器自身，访问宿主机服务时须配置实际可达地址。

## 参数、选择和容错

- 同一个模型可配置不同来源，在工作台按来源选择。模型 ID 的旧请求仍兼容；来源 ID 为不含地址的稳定引用。
- `priority` 数字越小越优先；相同优先级按正数 `weight` 加权选择。显式选择优先尝试该来源，失败仍尝试其余来源。
- 每条协议、地址和模型组合拥有独立连接及三态熔断；默认五次失败打开，60 秒后探测恢复。SDK 自动重试关闭，由统一路由降级。它只重试模型请求，不重放已经完成的工具副作用。
- `extra` 可设置 `temperature`、`max_tokens`、`max_completion_tokens`、`top_p`、`stop`、惩罚参数、`seed` 和 `extra_body`。原生 Anthropic 仅支持温度、`max_tokens`、`top_p`、`stop`；参数能否组合使用还受具体模型限制。
- 自定义正文不能覆盖 `model`、`messages`、`tools`、`tool_choice`、`stream`。端点拒绝嵌入凭证、查询和片段，配置最多 32 路。

例如兼容模型关闭特定思考选项：`"extra":{"temperature":0.2,"extra_body":{"enable_thinking":false}}`。参数名必须由提供方支持，不会自动转换所有厂商的私有参数。

凭证仅从服务端环境读取，浏览器展示标签、协议、模型和优先级；不展示地址、密钥或自定义正文。普通用户不能通过任务提示词新增服务端地址。未配置模型时仍可管理资料和记忆，任务执行会明确失败。

## 验证范围

协议测试使用真实 SDK 序列化与 HTTP 传输替身，验证路径、鉴权头、工具往返、来源选择、备用降级、非法配置及异常脱敏，不产生商业模型费用。真实商业服务的连通率、质量、上下文上限和工具成功率尚未验证；部署时先运行简单问答及一次只读工具任务。
