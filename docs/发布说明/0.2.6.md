# AegisCode 0.2.6

本版本让同一项目的不同目标拥有独立会话，并提供可定位任务的站内通知。

## 安装与使用

Windows选择安装器EXE或便携ZIP；Python用户安装wheel；源码支持本地与Docker启动。安装包仍为本地服务加浏览器工作台，运行不需要Node.js，模型需要自行配置。

1. 创建个人账号，在「项目」保存并启用目标与边界。
2. 从左侧项目树新建会话，分别讨论权限、性能或测试；支持改名、归档与恢复。
3. 顶部通知提供完成、失败、等待审批和需要核对的提醒；点击标记已读并定位任务，不会自动审批。
4. 从长期记忆与Skills审核启用个人偏好和经验，再按需复用。

## 旧库升级

全新数据库直接启用。旧库新增会话表和通知表需分别预览、备份迁移，完成后重启；建议先维护停写。

```powershell
AegisCode.exe --migrate-threads
AegisCode.exe --migrate-threads --apply --backup C:/AegisBackups/before-threads.sqlite
AegisCode.exe --migrate-notifications
AegisCode.exe --migrate-notifications --apply --backup C:/AegisBackups/before-notices.sqlite
```

自定义数据目录加 `--data-dir`；源码／wheel可用 `python -m app.harness.thread_migration` 和 `python -m app.harness.notification_migration`。SQLite备份文件必须不存在，PostgreSQL先完成pg_dump再提供备份文件。程序不替代数据库恢复演练。

## 本版新增

- 私有项目多会话、按需项目树、稳定分页、当前项目标签、改名、归档恢复。
- 会话创建幂等与归档／任务创建串行；同企业不同成员保持私有边界。
- 事务事件生成站内通知、未读数量、已读持久化、定位任务与读取失败重试。
- 历史会话和事件的显式备份迁移，可重复执行，不删除任务、资产或问答。
- 浏览器在本服务就绪后打开，显式 `--auto-port` 处理端口冲突。
- 会话历史分页、过期响应防护和导航内容增多后的滚动边界修复。

## 功能边界

定时任务、输入附件、模板探索、变更差异审阅、模型推理参数和逐Token流仍在计划中。子Agent目前只读，Worktree准备需审批。无原生WebView壳、自动合并或在线RL训练；不将历史无证据性能数字作为本版本收益。

界面截图和行为验收使用独立数据与确定性模型，商业模型质量需使用自己的模型和任务集验证。Windows构建未做代码签名，配置文件与模型权重不随包分发。
