# 任务模板、资料引用与外部工具导览

源码和公开0.2.8安装包均提供；无需新增数据库迁移。使用同一TypeScript／Vite／HTML/CSS工作台。

## 从模板开始

侧栏「任务模板」提供知识回答、只读代码审查、计算核对和复盘，每项展示所需能力与验收要求。点击「预填任务」仅填写输入框，不创建运行；补充目标、约束和示例后，再点「开始任务」。如果输入框已有内容，先选择保留或替换，不会静默覆盖。当前为内置模板，尚不支持自定义模板管理或企业共享模板。

只读代码审查基于粘贴代码或本人选定资料，不自动获得宿主任意目录权限。所需工具不可用的模板会禁用，并说明缺少能力。

## 引用本人资料

先在「知识库」上传TXT、Markdown或文本型PDF；扫描PDF需先OCR。回任务空间展开「引用本人资料」，刷新并选择最多3份。列表分批加载，只返回名称、ID和版本，不下载全部正文。已选标签可移除，新任务或退出清空选择。

开始任务时，服务端再次核对本人、同企业范围、文档类型、启用状态和非空正文。每份预览上限3000字符，总计上限9000字符；服务端按任务、规划及上下文预算进一步均衡缩短，并标注截断。若连每份128字符（短资料则为全文）也容不下，明确拒绝创建，请缩短任务、减少资料或提高预算。记录保留来源、版本和全文hash，不能将预览当作全文读取。

审批后的项目准备会增加工具消息，所以首次任务／规划模型调用前再次核对预算，保存实际快照与截断状态；仍无法容纳时任务明确失败，已审批工具可能已完成，应先核对执行记录。后续多轮工具调用仍按既有上下文规则裁剪，初始引用不代表每一轮都永久保留。需要更多证据时让Agent按需知识检索，并明确资料不足。

文档内容作为不可信资料，不赋予系统指令、工具或路径权限。子Agent不自动继承显式资料块，定时任务不接受显式资料选择；仍可通过原有私有知识检索工具处理可访问内容。

创建失败保留正文、选择和请求幂等键。服务端已提交但客户端丢失响应时，原内容重试返回原任务；修改资料选择会改变请求身份，同一旧键不同资料被拒绝。创建后即使原文档被修改或退役，重试找回原任务及其来源版本，不重跑工具。

![本人资料选择与任务输入](截图/任务输入/02-本人资料选择.png)

这是私有知识库资料引用，不是任意格式附件存储、可编辑附件或文件下载产品。资料上传沿用知识库的格式、大小及解析边界。

## 查看本人外部工具

「能力与设置 → 我的外部工具」显示获授权MCP服务名称、工具白名单及凭据是否配置。无授权或只读角色显示说明；管理员需在服务端配置服务与授权。页面不接受任意URL、自动安装或宿主命令。

“配置就绪·未连接验证”只表示配置和所需凭据存在。刷新目录不连接外部服务，不展示URL、密钥或环境变量值；实际工具发现及调用继续走工具审批、白名单与参数Schema检查。真实连接与服务可用性需另行验证。

## API

- `GET /api/v1/task-templates`：内置模板数组及所需能力可用性。
- `GET /api/v1/documents/references?limit=20&before=...`：私有启用非空资料元信息，最大50，游标必须属于当前范围。
- `POST /api/v1/runs`可选`document_ids`：最多3项，重复／无效ID拒绝；仍需`Idempotency-Key`。
- `GET /api/v1/mcp/servers`：本人授权配置，最多50服务、各64工具；`configuration_only=true`明确不含连通验证。

旧服务不含`task_inputs`能力字段时，资料控件与MCP导览隐藏，模板页显示升级提示，不影响原任务入口。
